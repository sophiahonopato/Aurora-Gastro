# 🍽️ Aurora Gastro

**Aurora Gastro** é um projeto desenvolvido como parte da minha **introdução à programação**, com foco em **HTML e CSS**, representando os primeiros passos na construção de interfaces para a web.

O projeto simula o site de um restaurante, com atenção à estrutura, organização visual e estilização.

---

## ✨ Sobre o projeto

O Aurora Gastro foi criado com o objetivo de aplicar, na prática, os conceitos iniciais de desenvolvimento web, explorando a construção de páginas estáticas e a importância do design e da semântica.

Este projeto marca o início da minha jornada na programação e serviu como base para compreender como a web funciona visualmente.

---

## 🧩 Tecnologias utilizadas

- HTML  
- CSS 

---

## 🎨 O que foi desenvolvido

- Estruturação de páginas utilizando HTML  
- Estilização com CSS  
- Organização de conteúdo e layout  
- Aplicação de conceitos básicos de design e responsividade  

---

## 📚 Aprendizados

Com este projeto, pude aprender e praticar:
- Estrutura básica de um site  
- Uso correto de tags HTML  
- Estilização e organização com CSS  
- Importância de um código limpo e bem estruturado  

Este projeto foi fundamental para o desenvolvimento da minha base em programação.
